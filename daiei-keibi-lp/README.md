# 大永警備 LP WordPressテーマ

株式会社大永警備の公式サイト兼ランディングページ用に制作した、クラシックPHPテーマです。採用応募を第一のコンバージョン、法人・事業者からの警備相談を第二のコンバージョンとして、ファーストビューからフォームまでの導線を設計しています。

## 動作要件

- WordPress 7.0.2で確認（WordPress 6.5以上を想定）
- PHP 8.0以上（PHP 8.4で構文確認）
- 外部CDN、jQuery、ビルドツール、必須プラグインなし
- `wp_mail()` を利用できるサーバー環境

## インストール

### WordPress管理画面からZIPをアップロードする

1. WordPress管理画面の「外観 > テーマ」を開きます。
2. 「新しいテーマを追加」から「テーマのアップロード」を選びます。
3. 納品ファイル `daiei-keibi-lp.zip` を選択し、「今すぐインストール」を押します。
4. インストール後に「有効化」を押します。
5. 「設定 > パーマリンク設定」を開き、変更せずに「変更を保存」を一度押します。

ZIPを展開した場合は、`daiei-keibi-lp` フォルダを `wp-content/themes/` に配置して有効化することもできます。

## 初期設定

### 1. 固定フロントページ

1. 「固定ページ > 新規固定ページを追加」で「ホーム」などのページを作成して公開します。本文は空でも構いません。
2. 「設定 > 表示設定」を開きます。
3. 「ホームページの表示」で「固定ページ」を選択します。
4. 「ホームページ」に作成したページを指定して保存します。

テーマの `front-page.php` がLP全体を表示します。テーマ有効化時に固定ページや投稿を自動生成することはありません。

### 2. メニュー

1. 「外観 > メニュー」でメニューを作成します。
2. カスタムリンクとして、以下のアンカーを必要に応じて追加します。
   - `/#services` 警備サービス
   - `/#business` 法人のお客様
   - `/#recruit` 採用情報
   - `/#jobs` 募集要項
   - `/#faq` よくある質問
   - `/#company` 会社概要
   - `/#contact` お問い合わせ
3. 表示位置「グローバルナビゲーション」または「フッターナビゲーション」に割り当てます。

メニュー未設定時は、テーマ内の基本メニューが表示されます。

### 3. テーマカスタマイザー

「外観 > カスタマイズ > 大永警備 LP 設定」から次の項目を変更できます。

- 会社情報
  - 正式社名
  - 住所
  - 電話番号
  - 代表者名
  - 設立年月
  - 警備業認定番号
  - 従業員数
  - 対応エリア
- ファーストビュー・CTA
  - メインコピー
  - サブコピー
  - 採用CTA文言
  - 法人CTA文言
  - ファーストビュー画像
- 採用連絡先
  - 採用専用電話番号
  - 採用担当者
  - 雇用形態
  - 面接場所
- フォーム・外部リンク
  - 問い合わせ受信用メールアドレス
  - プライバシーポリシーページ
  - Facebook、Instagram、XのURL
- ブランドカラー
  - メインカラー
  - アクセントカラー
- セクション表示
  - ファーストビュー以外の各LPセクションの表示・非表示

会社支給の理念文を「企業理念」セクションに同梱しています。表示の有無は「セクション表示」から切り替えられます。

会社支給の正式ロゴをテーマに同梱しています。「外観 > カスタマイズ > サイト基本情報」で別のロゴを登録した場合は、登録画像が優先されます。

## 募集情報の登録

1. 管理画面の「募集情報 > 新規追加」を開きます。
2. タイトルと必要に応じた説明本文を入力します。
3. 「募集条件」で募集職種、雇用形態、給与、勤務地、勤務時間、休日、応募資格、待遇、募集状況を入力します。
4. 公開するとフロントページの「募集要項」に表示されます。

募集情報が1件もない場合は、2026年8月1日に支給された正式な採用情報をテーマの初期募集要項として表示します。

- 雇用形態：アルバイト・パート
- 日勤：未経験者 日給8,500円～／資格保有者 日給9,000円～
- 夜勤：未経験者 日給11,600円～／資格保有者 日給12,600円～
- 勤務時間：日勤 8:00～17:00／夜勤 21:00～翌5:00
- 勤務日：1週間ごとの自由シフト、週2～3日から
- 応募資格：18歳以上、原付免許以上（自転車勤務は相談可能）
- 採用専用電話：090-1573-0761／担当 岡本

管理画面で公開済みの「募集情報」を登録すると、登録内容が初期募集要項に代わって表示されます。

## よくある質問の登録

1. 管理画面の「よくある質問 > 新規追加」を開きます。
2. 「質問」「回答」「表示順」を入力して公開します。
3. 1件以上公開されている場合は、登録済みFAQだけを表示します。
4. 登録がない場合は、正式な採用条件を反映した初期FAQを表示します。

表示中のFAQは、フロント画面のアコーディオンと `FAQPage` 構造化データの両方へ反映されます。

## 社員の声の登録

1. 管理画面の「社員の声 > 新規追加」を開きます。
2. 氏名またはイニシャル、年代、経験年数を入力します。
3. コメントを本文、写真をアイキャッチ画像に登録して公開します。

架空のコメントは表示しません。公開済みの社員の声がない場合、社員の声の領域自体を表示しません。本人の掲載同意を得た内容だけを登録してください。

## フォーム設定

法人お問い合わせフォームと採用応募フォームはテーマ内で実装されており、フォームプラグインは不要です。

### 送信先

「外観 > カスタマイズ > 大永警備 LP 設定 > フォーム・外部リンク」の「問い合わせ受信用メールアドレス」に正式な送信先を登録します。空欄または無効な場合は「設定 > 一般」の管理者メールアドレスへ送信します。

### メール送信

- 管理者通知と送信者への自動返信に `wp_mail()` を使用します。
- 本番環境では、送信ドメイン認証を設定したSMTPまたはホスティング事業者のメール送信機能で到達性を確認してください。
- 送信内容はWordPressデータベースへ保存しません。
- 入力エラー時の値は、そのリクエスト内だけで再表示し、永続保存しません。
- レート制限では送信内容ではなく、IPアドレスから生成した復元不能な一方向ハッシュだけを約1分間保持します。

### セキュリティ

各フォームにはWordPress nonce、サーバー側必須チェック、メール・電話番号の検証、サニタイズ、出力エスケープ、ハニーポット、短時間連投制限、個人情報同意チェック、メールヘッダーインジェクション対策を実装しています。採用応募は警備業法第14条に合わせ、18歳以上かをサーバー側で検証します。

## プライバシーポリシー

1. 固定ページを作成し、株式会社大永警備で確認済みの正式なプライバシーポリシー本文を登録します。
2. 必要に応じてページ属性のテンプレート「プライバシーポリシー」を選択します。
3. 「外観 > カスタマイズ > 大永警備 LP 設定 > フォーム・外部リンク」からページを指定します。

本文が空のときは、公開前に正式文面の登録が必要である旨だけを表示し、未確認の方針は自動生成しません。

## ロゴと画像の差し替え

- 同梱正式ロゴ：`assets/images/logo-daiei-full.png`、`assets/images/logo-daiei-mark.png`
- 別ロゴに差し替える場合：「外観 > カスタマイズ > サイト基本情報 > ロゴ」
- ファーストビュー画像：「外観 > カスタマイズ > 大永警備 LP 設定 > ファーストビュー・CTA」
- 同梱写真：`photo-hero.jpg`、`photo-about.jpg`、`photo-philosophy.jpg`
- 社員写真：「社員の声」のアイキャッチ画像

同梱写真は提供された大永警備の実際の現場・制服・寮の写真です。現場・制服の写真欄と寮紹介は表示設定から切り替えられます。ファーストビューは、被写体が左側、文字用の余白が右側にある横長写真を推奨します。未設定時は `photo-hero.jpg` を表示します。会社紹介と理念・採用の背景写真を差し替える場合は、同じファイル名のJPEGを適切に圧縮して置き換えてください。

## SEO・アクセシビリティ

- `title-tag`、メタディスクリプション、Canonical、OGP、Twitter Card
- Organization、WebSite、FAQPageのJSON-LD
- 主要SEOプラグイン検出時はテーマ側メタ情報の重複出力を停止
- セマンティックHTML、パンくずリスト、見出し階層
- スキップリンク、明確なフォーカス表示、フォームラベルとエラー通知
- `aria-expanded` 対応のモバイルメニューとFAQ
- キーボード操作可能なフォームタブ
- `prefers-reduced-motion` 対応
- JavaScript無効時も主要本文と両フォームを表示

## テーマ更新

1. 更新前にサイトとデータベースのバックアップを取得します。
2. ステージング環境で新しいZIPをアップロードし、表示とフォーム送信を確認します。
3. 同名テーマを置き換える場合は、ホスティング側のファイル管理またはSFTPで `wp-content/themes/daiei-keibi-lp` を更新します。
4. カスタマイザーや投稿に保存した内容はデータベース側にあるため通常は保持されますが、必ずバックアップを取得してください。

子テーマを使用せずテーマファイルを直接編集した場合、その変更は更新時に失われます。

## ZIPの再作成

ワークスペースの `daiei-keibi-lp` フォルダと同じ階層で実行します。

```bash
zip -r daiei-keibi-lp.zip daiei-keibi-lp \
  -x "*.DS_Store" \
  -x "__MACOSX/*" \
  -x "*.git*"
```

ZIPを展開したときの構造は次の状態にします。

```text
daiei-keibi-lp/
├── style.css
├── functions.php
├── front-page.php
├── screenshot.png
├── assets/
├── inc/
└── template-parts/
```

`style.css` がZIP直下ではなく、最上位の `daiei-keibi-lp` フォルダ内にあることを確認してください。

## 公開前確認事項

次の情報は未支給または実運用環境での確認が必要なため、公開前に登録・動作確認を行ってください。

- ファーストビュー用写真と使用許諾
- 問い合わせ受信用メールアドレス
- 正式なプライバシーポリシー
- SNSアカウント
- 電話受付時間
- 対応可能な現場条件
- 面接日入力フォームのURLと送信体制
- SMS・自動返信チャットの実運用設定
- 社会保険の加入条件と求人表現の最終確認
- フォーム自動返信文面
- メール送信テストと迷惑メール判定

## 公開前テスト

- 360、390、768、1024、1280、1440pxで横スクロールやレイアウト崩れがないこと
- PC／モバイルメニューをマウス、タッチ、キーボードで操作できること
- すべてのアンカーCTAと電話リンクが正しく動くこと
- 法人・採用の両フォームで、正常送信、入力エラー、連投制限、自動返信を確認すること
- 実運用サーバーで送信元ドメイン認証とメール到達性を確認すること
- FAQアコーディオンとフォームタブをキーボードで操作できること
- OSの「視差効果を減らす」設定で不要な動きが停止すること
- JavaScriptを無効にしても主要コンテンツが読めること
- 写真、プライバシーポリシーを正式情報へ置き換えたこと
- 採用条件と関連法令の表記を公開直前に最終確認したこと
